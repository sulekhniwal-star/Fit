### Security Threat Model (ASVS L1)
- **Threat**: Cross-tenant data leakage where User A queries or updates User B's health records or food logs.
- **Severity**: Critical
- **Mitigation**: Universal Row Level Security (RLS) enabled on 100% of tables with strict `auth.uid() = user_id` policies for select, insert, update, and delete; zero public unrestricted tables.
</threat_model>
