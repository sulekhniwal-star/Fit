<threat_model>
### Security Threat Model (ASVS L1)
- **Threat 1**: Brute force attacks on 6-digit SMS OTP codes.
- **Threat 2**: Accidental storage of raw bearer tokens in insecure client locations.
- **Severity**: High
- **Mitigation**: Enforce 60-second client-side cooldown on OTP resend; delegate secure session token storage to `supabase_flutter`'s secure storage layer; sanitize all auth failure messages.
</threat_model>
