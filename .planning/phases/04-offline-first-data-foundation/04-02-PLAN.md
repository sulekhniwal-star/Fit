<objective>
Implement Persistent Offline Outbox and Sync State Machine Coordinator (TASK 021 & 022).

Purpose: Guarantee that all user mutations are durable locally and synchronize reliably across volatile network conditions with exponential backoff and zero duplicate writes.
Output: Outbox mutation domain models, OutboxQueue implementation, SyncCoordinator with state machine, and automated test suites.
</objective>

<threat_model>
### Security Threat Model (ASVS L1)
- **Threat 1**: Duplicate network requests resulting in duplicate records on the server.
- **Threat 2**: App crash or kill during outbox transmission causing permanent data lock or loss.
- **Severity**: High
- **Mitigation**: Enforce unique client-generated UUID idempotency keys on every outbox mutation; implement startup recovery that resets `in_flight` mutations to `pending`.
</threat_model>
