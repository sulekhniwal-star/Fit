<threat_model>
### Security Threat Model (ASVS L1)
- **Threat 1**: Silent data loss or overwrite during multi-device or offline-to-online sync reconciliation.
- **Threat 2**: Realtime events leaking data across tenant boundaries.
- **Severity**: Critical
- **Mitigation**: Never silently overwrite material user edits; detect conflicts explicitly with `FK-3003`; ensure all Realtime channels enforce Postgres RLS.
</threat_model>
