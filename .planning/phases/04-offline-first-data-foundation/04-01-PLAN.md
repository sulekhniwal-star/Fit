<threat_model>
### Security Threat Model (ASVS L1)
- **Threat 1**: Extraction of sensitive user health telemetry from cleartext SQLite database files on compromised or backed-up devices.
- **Threat 2**: Database corruption or partial writes during sudden power loss or process kill.
- **Severity**: Critical
- **Mitigation**: Require SQLCipher 256-bit AES encryption pragma on database opening; wrap multi-entity updates in atomic local transactions.
</threat_model>
