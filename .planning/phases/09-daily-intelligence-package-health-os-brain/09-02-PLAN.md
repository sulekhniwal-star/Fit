## Objective
Implement the deterministic `DipRuleEngine` that evaluates multi-domain health telemetry against targeted lifestyle and cultural rules, sorts candidate actions by priority, and limits recommendations to a clean Top 3. Build the `DipRepository` that aggregates data across Drift repositories and exposes the reactive Riverpod DIP provider.

## Scope of Work

### 1. DIP Rule Engine (`lib/features/brain/domain/dip_rule_engine.dart`)
- Define rule interface: `DipRule` (`id`, `evaluate(DipContextInput input, DailyReadinessScore readiness) -> List<DipMicroAction>`).
- Implement 7 deterministic rules:
  1. `HydrationDeficitRule`: Triggered if hour $\ge 12$ and water $< 40\%$ of daily goal. Emits "Drink 500ml Water" micro-action (+35 priority).
  2. `PostMealShatapawaliRule`: Triggered if a meal $> 500\text{ kcal}$ was logged in the last 60 minutes. Emits "*Shatapawali* Post-Meal Walk" micro-action (+40 priority).
  3. `SedentaryBreakRule`: Triggered if hour $\ge 16$ and steps $< 3,000$. Emits "15-Minute Movement Refresh" micro-action (+30 priority).
  4. `HighFatigueRecoveryRule`: Triggered if readiness tier is `recovery` or ACWR $> 1.5$. Emits "Active Recovery & Gentle Asana" (+50 priority).
  5. `DinnerLogReminderRule`: Triggered if hour $\ge 20$ (8:00 PM) and no dinner logged today. Emits "Log Dinner" (+25 priority).
  6. `SleepWindDownRule`: Triggered if hour $\ge 22$ (10:00 PM). Emits "Begin Sleep Wind-Down" (+20 priority).
  7. `ColdStartOnboardingRule`: Triggered if 0 logs are present today. Emits "Log Morning Water & Sleep Check" (+45 priority).
- Implement `DipRuleEngine.assemblePackage(DipContextInput input)`:
  - Invokes `DailyReadinessCalculator`.
  - Evaluates all active rules.
  - Sorts candidate actions descending by priority score.
  - Synthesizes `DipFocusSignal` based on the highest-priority insight.
  - Clamps output `topActions` to at most 3 items (Cognitive Load Fence).
  - Returns complete `DailyIntelligencePackage`.

### 2. DIP Data Aggregation Repository (`lib/features/brain/data/dip_repository.dart`)
- `DipRepository`:
  - Injects `StepRepository`, `SleepRepository`, `VitalsRepository`, `NutritionRepository`, and `WorkoutRepository`.
  - Assembles `DipContextInput` for a user and target date.
  - Caches assembled `DailyIntelligencePackage` in memory / Drift for fast cold-start boot.
  - Emits reactive stream updates when any underlying domain table updates.
- Riverpod Providers:
  - `dipRuleEngineProvider`: Provides singleton `DipRuleEngine`.
  - `dipRepositoryProvider`: Provides `DipRepository` with all Drift repository dependencies wired.
  - `dailyIntelligencePackageProvider`: Asynchronous / reactive provider emitting today's DIP for the active user.
