# Phase 9 Plan 03: Contextual Home Surface, Micro-Action Cards & Routing Assembly

## Metadata
- **Phase**: 9 — Daily Intelligence Package & Health OS Brain

- **Focus**: Contextual home surface, interactive readiness card, micro-action feed, quick-log action bar, and routing assembly (TASK 056)
- **Status**: Ready to execute

## Objective
Construct the unified FitKarma Home Dashboard around the Daily Intelligence Package (DIP). Build the interactive `DailyReadinessCard`, the `DipActionFeed` displaying the top 3 micro-actions, the `QuickLogActionBar`, and assemble them into `HomeDashboardScreen` mounted as the primary authenticated destination (`/dashboard`).

## Scope of Work

### 1. Presentation Components (`lib/features/brain/presentation/`)
- `daily_readiness_card.dart`:
  - Glassmorphic Bento container with neon mint / saffron accents.
  - Large readiness score visual (0–100) with color-coded tier badge (`Peak`, `Optimal`, `Moderate`, `Recovery`).
  - Score headline and explanatory narrative.
  - Expandable / horizontal factor pills (`Sleep 85%`, `Vitals 92%`, `Strain 70%`, `Nutrition 60%`).
  - Explicit non-diagnostic wellness disclosure footnote.
- `dip_action_feed.dart`:
  - Contextually renders up to 3 `DipMicroAction` items.
  - Visual category icon, priority badge, and cultural context tag (e.g. *Shatapawali*).
  - Primary action button navigating to target feature (e.g. quick hydration, meal log, workout timer).
  - Dismiss button removing action from active view.
- `quick_log_action_bar.dart`:
  - One-tap quick entry bar for rapid daily habit tracking:
    - **+250ml Water**: Directly adds 250ml water entry to local store.
    - **Log Meal**: Routes to nutrition search or bottom sheet.
    - **Start Workout**: Routes to `/workouts`.
    - **Log Weight**: Opens weight logger bottom sheet.
- `home_dashboard_screen.dart`:
  - Unified home surface replacing initial prototype.
  - Time-of-day contextual greeting (*"Namaste, User"*, *"Good Morning / Afternoon / Evening"*).
  - App bar with `SyncStatusBadge` and settings navigation pill.
  - Vertical scrollable layout:
    1. Greeting & date pill
    2. `DailyReadinessCard`
    3. `DipActionFeed` (Top 3 Micro-Actions)
    4. Today's Summary Row (Steps, Calories, Sleep, Water with tap-to-drilldown navigation)
    5. `QuickLogActionBar`
  - Pull-to-refresh to trigger immediate DIP recalculation.

### 2. App Router Integration (`lib/app/router/app_router.dart`)
- Update `RouteNames.dashboard` (`/dashboard`) route builder to render `HomeDashboardScreen`.
- Ensure clean transitions to `/nutrition`, `/workouts`, `/settings`, and modal sheets.

### 3. Widget & Scenario Tests (`test/features/brain/home_dashboard_screen_test.dart`)
- Scenario 1: **Morning Boot**: High readiness, morning hydration micro-action visible.
- Scenario 2: **Post-Meal Afternoon**: *Shatapawali* walk micro-action rendered with deep-link button.
- Scenario 3: **High Fatigue / Strain**: Recovery tier alert with active rest guidance.
- Scenario 4: **Cold Start / Zero Logs**: Clean onboarding prompts without broken UI states.
- Scenario 5: **Quick Logging**: Tapping "+250ml Water" on the action bar increments water count and updates reactive dashboard.
