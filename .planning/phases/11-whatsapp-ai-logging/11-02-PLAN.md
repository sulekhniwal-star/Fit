# Phase 11 Plan 02: Audio Transcription & Conversational Pipeline

## Metadata
- **Phase**: 11 — WhatsApp AI Logging
- **Plan**: 11-02
- **Focus**: WhatsApp voice note download, Groq Whisper transcription, DPDP 2023 ephemeral media handling, and meal parsing
- **Status**: Ready to execute

## Objective
Build the conversational speech and text pipeline for WhatsApp. Integrate Meta Graph API media downloading with Groq's `whisper-large-v3` speech-to-text model for Indian languages, enforce zero-disk ephemeral audio retention (DPDP Act 2023), and connect transcribed or direct text inputs to the `ai-gateway` meal analyzer and medical boundary guardrails.

## Scope of Work

### 1. Ephemeral Media Fetcher (`supabase/functions/whatsapp-webhook/media_fetcher.ts`)
- `fetchWhatsAppAudio(mediaId: string, accessToken: string): Promise<Uint8Array>`:
  - Calls Meta Graph API endpoint: `GET https://graph.facebook.com/v21.0/{mediaId}`.
  - Retrieves temporary audio download URL.
  - Streams audio file (OGG Opus) directly into memory as a `Uint8Array`.
  - Enforces 15-second download timeout and 10MB maximum file size limit.
  - **DPDP Act 2023 Ephemeral Guarantee**: No audio is written to disk or object storage.

### 2. Audio Transcriber (`supabase/functions/whatsapp-webhook/audio_transcriber.ts`)
- `transcribeAudio(audioBytes: Uint8Array, groqApiKey: string): Promise<string>`:
  - Formulates multipart form-data for Groq Whisper completions: `POST https://api.groq.com/openai/v1/audio/transcriptions`.
  - Model: `whisper-large-v3`.
  - System prompt: `"Indian meal logging voice note in Hindi, English, or Hinglish: roti, dal, sabzi, katori, chawal, dahi, paneer."`.
  - Immediately zeroes and drops audio buffer after API request dispatch.
  - Returns sanitized transcript text.

### 3. Conversational Meal Extraction (`supabase/functions/whatsapp-webhook/meal_pipeline.ts`)
- Ingests text from either:
  - Inbound text message (`message.text.body`).
  - Audio transcription from `transcribeAudio`.
- Enforces Medical Boundary Guardrail:
  - Detects clinical disease treatment or prescription queries.
  - If clinical claim detected: sends polite statutory non-diagnostic refusal.
- Calls `ai-gateway` meal analyzer (`llama-3.3-70b-versatile`):
  - Parses dishes, portion quantities, household units (`katori`, `piece`, `glass`), cooking states, and tadka levels.
  - Aggregates macro estimates (Calories, Protein, Carbs, Fat).
  - Generates culturally supportive Hinglish coaching summary.
- Updates `whatsapp_interactions` record with `candidate_items`, macros, and `status: 'pending'`.

### 4. Pipeline Tests (`supabase/functions/whatsapp-webhook/pipeline_test.ts`)
- Test 1: Audio media fetcher constructs proper Meta Graph API headers and parses download URL.
- Test 2: Audio transcriber properly handles mock audio payload and returns Hindi/Hinglish transcription.
- Test 3: Ephemeral memory lifecycle verifies audio buffer is discarded without disk writes.
- Test 4: Medical boundary guardrail blocks clinical diagnostic prompts over WhatsApp.
- Test 5: Full conversational pipeline processes Hindi voice transcript into candidate meal items.
