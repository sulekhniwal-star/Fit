- **Phase**: 11 — WhatsApp AI Logging

## Objective
Complete the end-to-end loop for WhatsApp AI logging. Send interactive Quick Reply messages to the user displaying detected dishes and macros, process interactive button callbacks (`Confirm & Log`, `Cancel`), persist confirmed food entries directly to `public.food_logs`, send updated daily macro confirmations over WhatsApp, and verify seamless sync reflection in the mobile app.

## Scope of Work

### 1. Interactive WhatsApp Card Builder (`supabase/functions/whatsapp-webhook/card_builder.ts`)
- Formats interactive WhatsApp Quick Reply button message:
  - Header: `🍽️ FitKarma Meal Estimate`
  - Body:
    - Itemized candidate list with portions and calories:
      - e.g. `• 2 Phulka / Roti (~160 kcal)`
      - e.g. `• 1 Medium Katori Dal Tadka (~180 kcal)`
    - Total macro summary: `Total: ~340 kcal | P: 15g | C: 54g | F: 7g`
    - Hinglish insight: e.g. `Accha protein balance hai!`
    - Statutory Non-Medical Disclaimer: `⚠️ FitKarma estimate only. Not medical advice.`
  - Action Buttons (Max 3):
    1. `✅ Confirm & Log` (payload: `confirm_meal_{interaction_id}`)
    2. `❌ Cancel` (payload: `cancel_meal_{interaction_id}`)
- Sends message via Meta Graph API `POST /v21.0/{phone_number_id}/messages`.

### 2. Button Callback Handler & Meal Committer (`supabase/functions/whatsapp-webhook/commit_handler.ts`)
- Processes inbound `interactive.button_reply`:
  - Parses `button_reply.id`:
    - `confirm_meal_{interaction_id}`:
      - Fetches interaction from `whatsapp_interactions`.
      - Verifies interaction is in `pending` state and not expired (< 6 hours old).
      - Inserts verified meal items into Supabase Postgres `public.food_logs`:
        - `id`: UUID
        - `user_id`: linked user ID
        - `logged_at`: timestamp of original message
        - `meal_slot`: inferred from time of day (Breakfast, Lunch, Dinner, Snack)
        - `food_name`: candidate item name
        - `portion_quantity`, `portion_unit`, `calories`, `protein_grams`, `carbs_grams`, `fat_grams`
      - Updates interaction status to `confirmed`.
      - Computes updated daily calories and sends confirmation message to user:
        `"✅ Logged 2 items to your Lunch! Today's total: 1,450 kcal. Keep it up! 🎯"`
    - `cancel_meal_{interaction_id}`:
      - Updates interaction status to `cancelled`.
      - Sends acknowledgement: `"Meal log cancelled. You can log anytime!"`.
