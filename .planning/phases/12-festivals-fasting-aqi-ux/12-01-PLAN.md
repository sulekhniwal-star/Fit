# Plan 12-01: Fasting Tracker & Indian Fast Protocols

## Metadata
- **Phase**: 12 (Festivals, Fasting, AQI & India-First UX)
- **Plan**: 12-01
- **Focus**: Fasting Domain Models, Indian Fast Protocols, Drift Persistence & Interactive Timer UX
- **Requirements**: `CULT-01`, `TASK 069`
- **Dependencies**: Phase 4 (Drift Offline Database), Phase 5 (Health Data Core), Phase 6 (Indian Nutrition Engine)

## Objective
Implement voluntary, user-selected fasting modes supporting intermittent fasting (16:8, 14:10, 12:12, 18:6, 20:4) and traditional Indian cultural fasts (Navratri, Ekadashi, Karwa Chauth, Ramadan, Custom). Build the full offline-first Drift storage, active fasting state machine, live metabolic phase computation, hydration reminder rules, and safe refeeding guidance with zero religious inference.

## Implementation Tasks

### 1. Fasting Domain Models & State Machine
- Path: `lib/features/cultural/domain/fasting_protocol.dart`, `fasting_session.dart`, `fasting_phase.dart`, `safe_refeeding_guide.dart`
- Core Constructs:
  - `enum FastingProtocolType { if16_8, if14_10, if12_12, if18_6, if20_4, navratri, ekadashi, karwaChauth, ramadanRoza, custom }`
  - `enum FastingStage { anabolic, digestion, gluconeogenesis, ketosisTransition, fatBurning, deepAutophagy }`
  - `class FastingSession`:
    - `id`, `userId`, `protocolType`, `startTime`, `plannedEndTime`, `actualEndTime`, `status` (`active`, `completed`, `cancelled`), `isWaterless` (e.g. Nirjala / Karwa Chauth / Roza), `hydrationRemindersEnabled`, `notes`.
  - `class FastingPhaseCalculator`:
    - Computes elapsed duration, remaining duration, progress percentage (0.0 to 1.0+), and current metabolic phase based on elapsed hours.
  - `class SafeRefeedingGuide`:
    - Provides tailored Indian meal suggestions for breaking fasts (warm lemon water, tender coconut water, moong dal khichdi, soaked nuts, papaya).

### 2. Drift Database Schema & Offline Repository
- Path: `lib/features/cultural/data/fasting_sessions_table.dart`, `drift_fasting_repository.dart`
- Table definition:
  - `FastingSessions`:
    - `id` (Text, PK)
    - `user_id` (Text)
    - `protocol_type` (Text)
    - `start_time` (DateTime)
    - `planned_end_time` (DateTime)
    - `actual_end_time` (DateTime, nullable)
    - `status` (Text: active/completed/cancelled)
    - `is_waterless` (Bool, default false)
    - `hydration_reminders` (Bool, default true)
    - `created_at` (DateTime)
    - `updated_at` (DateTime)
- `DriftFastingRepository`:
  - Methods: `getActiveSession(userId)`, `startSession(session)`, `completeSession(id, endTime)`, `cancelSession(id)`, `getSessionHistory(userId, limit)`.
  - Ties into Outbox queue for seamless Supabase synchronization.

### 3. Fasting State Notifier & Adaptive Reminders
- Path: `lib/features/cultural/presentation/fasting_state_notifier.dart`
- Responsibilities:
  - Streams active fasting session from Drift.
  - Provides actions: `startFast(...)`, `endFast(...)`, `cancelFast(...)`.
  - Non-Negotiables:
    - Never infer religion or auto-enroll users.
    - During active fasts, automatically signal to suppress irrelevant "You haven't logged lunch/dinner" notifications.
    - Adapt hydration reminders: For standard fasts, ensure regular water alerts; for Nirjala/dry fasts (`isWaterless: true`), suppress water alerts until fast completion.

### 4. Fasting Presentation & Interactive UI
- Path: `lib/features/cultural/presentation/fasting_tracker_card.dart`, `fasting_screen.dart`, `refeeding_guidance_sheet.dart`
- UI Components:
  - Bento-style `FastingTrackerCard` on Dashboard showing active timer, circular progress bar, and current metabolic phase chip.
  - `FastingScreen` with full protocol selector, stage explanation carousel, and manual start/stop controls.
  - `RefeedingGuidanceSheet` appearing when the user ends a fast >= 14 hours, offering soothing, easily digestible Indian meal recommendations.

### 5. Automated Verification & Tests
- Path: `test/features/cultural/fasting_protocol_test.dart`, `test/features/cultural/fasting_repository_test.dart`, `test/features/cultural/fasting_ui_test.dart`
- Test Scenarios:
  1. Fasting protocol definitions, planned hours calculation, and waterless fast flags.
  2. `FastingPhaseCalculator` returns exact metabolic stages as hours progress (0-4h, 4-8h, 8-12h, 12-16h, 16h+).
  3. Timezone stability: Daylight saving or Indian Standard Time (IST) offset changes do not skew start/end timestamps.
  4. Repository lifecycle: start, retrieve active, complete, and fetch history from in-memory Drift database.
  5. Refeeding advice correctly formats Indian recovery meals.
  6. Widget rendering: `FastingTrackerCard` updates elapsed time and renders progress bar cleanly.

- Interactive Flutter UI (Bento card + Fasting screen + Refeeding sheet).
