# Plan 12-02: Real-Time AQI Engine & Outdoor Workout Safety Adaptor

## Metadata
- **Phase**: 12 (Festivals, Fasting, AQI & India-First UX)
- **Plan**: 12-02
- **Focus**: CPCB NAQI Standard, AQI Data Provider Abstraction, Privacy-Conscious Location & Workout Safety Adaptor
- **Requirements**: `CULT-01`, `TASK 070`
- **Dependencies**: Phase 7 (Workout & Fitness Core), Phase 9 (Daily Intelligence Package)

## Objective
Build an offline-resilient, privacy-preserving Air Quality Index (AQI) engine adhering to India's Central Pollution Control Board (CPCB) NAQI scale. Dynamically evaluate outdoor workout risks (running, cycling) against local pollution levels, recommend indoor alternatives (indoor treadmill, HIIT, Surya Namaskar, yoga) on high pollution days, and protect user privacy with coarse city-level resolution or manual city selection.

## Implementation Tasks

### 1. CPCB NAQI Domain Models & Workout Safety Classifier
- Path: `lib/features/cultural/domain/aqi_models.dart`, `aqi_workout_advisory.dart`
- Core Constructs:
  - `enum CpcbAqiCategory { good, satisfactory, moderate, poor, veryPoor, severe }`
    - CPCB Band boundaries: Good (0-50), Satisfactory (51-100), Moderate (101-200), Poor (201-300), Very Poor (301-400), Severe (401-500+).
    - Color tokens: `#4CAF50`, `#8BC34A`, `#FFEB3B`, `#FF9800`, `#F44336`, `#9C27B0`.
  - `class AqiReading`:
    - `aqi` (int), `category` (CpcbAqiCategory), `pm25` (double?), `pm10` (double?), `city` (string), `stationName` (string?), `recordedAt` (DateTime), `isStale` (bool).
  - `class AqiWorkoutAdvisory`:
    - Evaluates proposed workout (e.g., outdoor run, cycling) against AQI.
    - If `category >= CpcbAqiCategory.poor`:
      - Flags outdoor hazard.
      - Automatically generates recommended indoor alternative: e.g., Outdoor Run -> Indoor Treadmill Interval or 20-min HIIT; Outdoor Cycling -> Stationary Bike or Surya Namaskar.
      - Provides respiratory precaution notes (N95 mask advice if outside transit is unavoidable, air purifier recommendation indoors).

### 2. Privacy-Conscious AQI Provider & Caching Service
- Path: `lib/features/cultural/data/aqi_service.dart`, `mock_aqi_provider.dart`
- Architecture:
  - `abstract class AqiDataProvider`:
    - `Future<AqiReading> getAqiForLocation({String? city, double? latitude, double? longitude})`
  - Privacy Guarantees (DPDP Act 2023):
    - Never requires precise GPS lat/long; supports coarse district level or 100% manual city selection (50+ curated Indian cities: Delhi NCR, Mumbai, Bengaluru, Kolkata, Chennai, Hyderabad, Pune, Ahmedabad, Lucknow, Patna, Jaipur, etc.).
    - Zero external transmission of user device identifiers.
  - In-Memory & Local Cache:
    - 2-hour TTL cache to minimize network calls and conserve battery.
    - Graceful offline fallback: returns last cached reading tagged with `isStale = true` or a neutral default with "Offline" badge.

### 3. Workout & DIP Adaptive Integration
- Path: `lib/features/cultural/presentation/aqi_state_notifier.dart`, `aqi_context_card.dart`
- Responsibilities:
  - Exposes `aqiStateNotifierProvider` streaming the current AQI and active advisory.
  - One-tap city switcher allowing users to manually toggle their Indian city without granting location permissions.
  - Integrates with Daily Intelligence Package (DIP) and Workout Quick-Start screen: If user taps "Outdoor Run" while AQI is Poor/Very Poor, displays a friendly dismissible safety alert with a "Switch to Indoor Workout" one-tap action.

### 4. Interactive AQI Presentation & Detail Sheet
- Path: `lib/features/cultural/presentation/aqi_badge.dart`, `aqi_details_sheet.dart`
- UI Elements:
  - Bento `AqiContextCard` featuring CPCB color-coded badge, AQI numeric value, city name, and concise workout advice ("Safe for outdoor runs" vs "Switch to indoor workouts today").
  - `AqiDetailsSheet` with PM2.5/PM10 pollutant breakdown, respiratory health safety tips, and city selector.

### 5. Automated Verification & Tests
- Path: `test/features/cultural/aqi_domain_test.dart`, `test/features/cultural/aqi_service_test.dart`, `test/features/cultural/aqi_widget_test.dart`
- Test Scenarios:
  1. CPCB NAQI threshold classification accurately matches all 6 official bands (0-50, 51-100, 101-200, 201-300, 301-400, 401+).
  2. Outdoor vs indoor workout recommendation generator triggers indoor alternatives on AQI >= 201.
  3. Cache invalidation after 2-hour TTL and fallback to cached data when offline.
  4. Missing/denied location permission falls back cleanly to default or manual city without throwing errors.
  5. Widget rendering: `AqiContextCard` renders proper CPCB category color and city name.
