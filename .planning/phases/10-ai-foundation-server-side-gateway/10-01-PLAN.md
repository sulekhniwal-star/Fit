# Phase 10 Plan 01: Server-Side AI Gateway & Safety Boundary

## Metadata
- **Phase**: 10 — AI Foundation & Server-Side Gateway
- **Plan**: 10-01
- **Focus**: Supabase Edge Function AI Gateway, Groq multi-model routing, JSON Schema structured output contracts, PII redaction, and medical safety boundary (TASK 058, TASK 059, TASK 063)
- **Status**: Ready to execute

## Objective
Deploy a secure server-side AI gateway via Supabase Edge Functions (`supabase/functions/ai-gateway/`) powered by Groq. Create task-based model routing (`llama-3.3-70b-versatile`, `llama-3.2-11b-vision-preview`, `llama-3.1-8b-instant`), strict JSON Schema enforcement, PII minimization, rate limiting, and automated medical boundary guardrails.

## Scope of Work

### 1. Supabase Edge Function AI Gateway (`supabase/functions/ai-gateway/`)
- `index.ts`:
  - Entry point handling `POST /ai-gateway`.
  - Validates standard request envelope (`request_id`, `idempotency_key`, `payload`) from `_shared/envelope.ts`.
  - Verifies Supabase Auth JWT token (or bypasses for local testing with mock headers).
  - Routes requests based on `task_type`:
    - `meal_text_analysis`
    - `meal_photo_analysis`
    - `hinglish_coaching`
  - Returns standard response envelope with `request_id`, `data`, `warnings`, and typed `error` (`FK-4001` for rate limits, `FK-5001` for upstream LLM timeouts, etc.).
- `groq_client.ts`:
  - Wraps Groq API (`https://api.groq.com/openai/v1/chat/completions`) using `GROQ_API_KEY`.
  - Routes model:
    - Text parsing $\rightarrow$ `llama-3.3-70b-versatile`.
    - Image food detection $\rightarrow$ `llama-3.2-11b-vision-preview`.
    - Hinglish narrative $\rightarrow$ `llama-3.1-8b-instant`.
  - Configures retry policy (max 2 retries on 429/503 with exponential backoff) and 15-second timeout.
  - Enforces `response_format: { type: "json_object" }`.
- `schemas.ts`:
  - Strict JSON schemas for `meal_analysis_response` and `photo_analysis_response`:
    - `items`: Array of candidate foods with `food_name`, `quantity`, `unit`, `cooking_state`, `tadka_level`, `calories`, `protein_g`, `carbs_g`, `fat_g`, `confidence`.
    - `confidence_overall`: Numeric 0.0 to 1.0.
    - `uncertainty_reasons`: Array of strings explaining why estimates may vary.
    - `hinglish_insight`: Short conversational coaching phrase.
    - `statutory_disclaimer`: Mandatory non-clinical disclosure.
- `guardrails.ts`:
  - `sanitizePromptText`: Scrubs Indian phone numbers (`+91...`, `9xxxxxxxxx`), email addresses, and auth tokens.
  - `enforceMedicalBoundary`: Post-inference check. Rejects responses making clinical diagnosis or claiming Ayurvedic cures for chronic disease, replacing with safe statutory wellness phrasing.

### 2. Edge Function Mock & Unit Verification

  - PII scrubbing on input prompts.

  - Medical claim suppression & disclaimer attachment.
  - Error envelope generation on malformed payloads.
